# RekordBox to MusicBee Playlist Converter Plugin

## Purpose
This MusicBee plugin takes a RekordBox library export XML and converts it into a set of playlists in MusicBee.

## How To Run
1. Build the project or download the .dll file from the Releases of this repository
2. Move all contents of bin folder to your MusicBee Plugins folder (or just the downloaded .dll file)
3. Export RekordBox library by selecting File > Export collection in xml format
4. Start MusicBee
5. Start plugin by selecting Tools > Convert RekordBox Library
6. Click the big button and select the saced XML
